# 디자인 레퍼런스

UI/UX 설계 때 참고할 외부 자료를 모아 둔다. 사용자가 미리 제공한 것이며, 아직 화면 설계 단계가 아니라 내용을 분석하거나 결정에 반영하지 않았다. 참고할 때 이 문서에 무엇을 취할지 적는다.

| 자료 | 링크 | 제공 | 메모 |
|---|---|---|---|
| Hangly 케이스 스터디 (Designs by Jenn) | https://designsbyjenn.ca/case_studies/Hangly/hangly_index.html | 2026-09-30 사용자 | 미열람. 화면 설계 시작 시 내용을 읽고 취할 점과 버릴 점을 여기에 기록한다 |

- 사용자가 준 원문 링크: `https://designsbyjenn.ca/case_studies/Hangly/hangly_index.html?utm_source=chatgpt.com`. 표의 링크는 추적 매개변수(`utm_source`)만 뺀 것이다.
- 화면 설계는 상세 설계 1~9의 "현재 구현 차이" 절(iOS 쪽 어긋남)을 먼저 확인한 뒤 시작한다.

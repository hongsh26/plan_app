# 진행 상황

## 현재

- iOS 앱, SwiftUI/iOS 17, EventKit 우선 연동으로 구현 방향을 확정했다.
- `src/new/`에 XcodeGen 프로젝트 정의와 SwiftUI 앱 골격을 추가했다.
- 메모리 기반 데모 Party, 공개 수준 모델, 공통 가능 시간 계산, 약속 제안, EventKit 권한 및 일정 읽기 경계를 구현했다.
- 공통 시간 계산 단위 테스트 4개를 추가했다.

## 다음 작업

1. macOS에서 XcodeGen으로 프로젝트 생성 후 Xcode 빌드 및 테스트 실행.
2. 앱 서명용 개발 팀과 고유 번들 ID 설정.
3. 인증/서버 기술 및 공개 범위·확정·Party 제한/탈퇴 정책 확정.
4. Party 생성·초대와 제안 응답·확정 상태 전이 구현.
5. 로컬 영속화와 실제 캘린더 쓰기/변경/취소 구현.
6. 서버 동기화 → 알림 → 결제 → 통합 검증 순서로 진행.

## 유의 사항

- 원본 MVP의 Apple/Google 연동과 결제는 출시 범위에 유지한다.
- 기존 코드가 추가되거나 발견되면 `src/base/` 실행 가능성을 보존한다.
- 현재 작업 환경에는 Swift/Xcode/XcodeGen이 없어 실제 컴파일 및 iOS 테스트는 수행하지 못했다.
- 현재 앱 데이터는 메모리에만 보관되어 재실행 시 초기화된다.

PlanTogether 화면 시안

디자인 시스템 토큰으로 그린 정적 시안이다. Party 목록, 공통 가능 시간 결과, 제안 응답 세 화면. 결과 화면에는 사람 수·아바타·원인이 없고, 제안 화면에는 설계 7이 공개하는 참여자별 응답이 있다.

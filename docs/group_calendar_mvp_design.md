# 그룹 일정 관리 앱 MVP 설계서

## 1. 제품 개요

### 한 줄 정의
연인·친구·가족과 일정을 공유하고, 모두가 가능한 시간을 자동으로 찾아 약속까지 잡아주는 그룹 캘린더 앱.

### 핵심 가치
- 개인 캘린더를 그대로 활용
- 파티(그룹) 단위로 일정 공유
- 서로의 가능한 시간을 자동 계산
- 일정 제안부터 확정까지 한 번에 처리
- 일정 공개 범위를 관계별로 제어

---

## 2. 핵심 제품 구조

앱의 핵심 객체는 다음 네 가지로 구성한다.

- `User`
- `Party`
- `Calendar`
- `Event`

```text
User
 ├─ Personal Calendar
 ├─ Party A
 │   ├─ Members
 │   ├─ Shared Schedule
 │   └─ Proposed Events
 │
 ├─ Party B
 │   ├─ Members
 │   ├─ Shared Schedule
 │   └─ Proposed Events
 │
 └─ Subscription
```

사용자는 하나 이상의 개인 캘린더를 연결할 수 있고, 여러 개의 Party에 참여할 수 있다.

Party는 별도의 캘린더를 새로 작성하는 공간이라기보다, 사용자의 기존 일정 중 어떤 정보를 해당 그룹에 어느 정도 공개할지를 결정하는 관계 단위로 사용한다.

## 5. 일정 공개 범위

일정 공유의 핵심은 사용자의 원본 캘린더를 그대로 공개하지 않고, Party마다 다른 수준으로 일정을 공개할 수 있도록 하는 것이다.

### 예시 일정

```text
월요일
14:00 ~ 16:00
교수님 미팅
```

### Party별 공개 방식

#### 상세 공개

```text
14:00 ~ 16:00
교수님 미팅
```

#### Busy Only

```text
14:00 ~ 16:00
일정 있음
```

#### 숨김

해당 Party에 일정이 표시되지 않음.

### Party별 공개 예시

```text
Personal Calendar
      │
      ├─ 연인 Party → 상세 공개
      ├─ 가족 Party → Busy Only
      └─ 친구 Party → 가능 시간만 공유
```

## 6. 공통 가능 시간 계산

이 기능은 앱의 핵심 Hero Feature로 정의한다.

### 입력 예시

```text
A: 18:00 이후 가능
B: 19:00 이후 가능
C: 17:00 ~ 20:00 가능
D: 19:00 이후 가능
```

### 계산 결과

```text
오늘 공통 가능 시간

19:00 ~ 20:00
4 / 4 가능
```

향후에는 다음과 같이 부분 가능 시간도 제공할 수 있다.

```text
18:00 ~ 19:00
2 / 4 가능

19:00 ~ 20:00
4 / 4 가능

20:00 ~ 22:00
3 / 4 가능
```

## 7. 일정 제안

사용자는 공통 가능 시간 또는 임의의 시간을 선택하여 Party에 일정을 제안할 수 있다.

### 예시

```text
새 약속

제목
대학 친구 모임

날짜
9월 12일

시간
19:00 ~ 21:00

장소
미정

참여자
4명

[약속 제안]
```

### 알림 예시

```text
대학 친구 Party

새로운 일정이 제안되었습니다.

9월 12일 19:00
저녁 모임

[수락] [거절]
```

---

## 8. 일정 확정

멤버들의 응답 결과에 따라 일정이 확정된다.

```text
A ✅
B ✅
C ✅
D ✅
```

모든 멤버 또는 사용자가 정의한 기준을 만족하면 일정이 확정된다.

```text
일정이 확정되었습니다.

9월 12일
19:00 ~ 21:00
```

확정 이후에는 각 사용자의 Apple Calendar 또는 Google Calendar에 일정을 반영한다.

## 10. 결제 모델

초기 MVP에서는 복잡한 요금제를 피하고 단순한 구조로 시작한다.

### Free

- Party 최대 2개
- 기본 캘린더 연동
- 일정 공유
- 공통 시간 계산
- 일정 제안 / 수락 / 거절
- 기본 알림

### Premium

- Party 무제한
- 고급 공개 설정
- 반복 일정
- 고급 알림
- 여러 개의 캘린더 연동
- 향후 Widget 지원

### 기본 과금 방향

```text
Free
Party 2개

Premium
Party 무제한
```

가격은 실제 사용자 테스트와 시장 검증 이후 확정한다.

## 12. MVP 검증 포인트

### 1. Party 생성률
사용자가 실제로 연인, 친구, 가족 등의 Party를 생성하는지 확인한다.

### 2. 캘린더 연결률
사용자가 개인 캘린더 접근 권한을 허용하고 실제로 연동하는지 확인한다.

### 3. 공통 시간 탐색 사용률
사용자가 반복적으로 공통 시간 찾기 기능을 사용하는지 확인한다.

### 4. 일정 제안 전환율
공통 시간을 확인한 뒤 실제 일정 제안으로 이어지는지 확인한다.

### 5. Party 확장률
한 사용자가 하나의 Party에만 머무르지 않고 여러 Party를 생성하는지 확인한다.

### 6. 유료 전환 가능성
무료 Party 제한에 도달했을 때 Premium 결제로 이어지는지 확인한다.

## 14. 제품 차별화 방향

일반 공유 캘린더와 차별화하기 위해 중심 가치를 다음과 같이 설정한다.

### 일반 공유 캘린더
> 우리 일정을 같이 기록한다.

### 본 앱
> 우리가 언제 만날 수 있는지 자동으로 찾아준다.

즉, 제품의 중심은 단순한 Calendar Sharing이 아니라 다음 세 요소의 결합이다.

```text
Calendar Sharing
      +
Party
      +
Free Time Matching
```

## 15. MVP 목표

MVP의 목표는 기능을 많이 제공하는 것이 아니라 다음 질문을 검증하는 것이다.

> 사람들이 연인, 친구, 가족과 약속을 잡기 위해 실제로 이 앱을 반복해서 사용할 것인가?

이를 확인하기 위해 MVP에서는 다음 흐름이 반드시 매끄럽게 동작해야 한다.

```text
Calendar 연결
    ↓
Party 생성
    ↓
멤버 초대
    ↓
일정 공유
    ↓
공통 시간 계산
    ↓
일정 제안
    ↓
수락 / 거절
    ↓
일정 확정
```

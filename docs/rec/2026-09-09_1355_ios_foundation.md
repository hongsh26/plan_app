# iOS 앱 기반 구현 기록

- 방향 확정: iOS 17, SwiftUI, EventKit 우선 연동.
- 구현: 탭 기반 화면, Party 목록/상세, 데모 멤버와 일정, 공통 가능 시간 계산, 약속 제안, 설정 화면.
- 캘린더: 전체 접근 권한 요청과 앞으로 7일의 이벤트 읽기 경계를 구현했다.
- 검증 코드: 공통 시간에서 Busy 제외, 최소 길이, 범위 밖 일정 처리 테스트를 추가했다.
- 프로젝트: XcodeGen 정의 및 macOS 실행 안내를 추가했다.
- 검증 제약: 현재 Linux/WSL 환경에는 Swift, Xcode 및 XcodeGen이 없어 컴파일과 iOS 런타임 검증을 수행하지 못했다.
- 재검토 반영: 오늘의 지난 시간과 22시 이후 제외, 모든 멤버 동기화 확인, 실패 시 동기화 상태 무효화, 1시간 단위 슬롯 생성, 멤버별 공개 설정과 Busy Only 제목 제거를 보완했다.
- 다음 작업: macOS 빌드/테스트, 서명 설정, 인증/서버 선택, Party 생성·초대 및 제안 응답/확정 구현.
